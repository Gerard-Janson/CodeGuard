# CodeGuard

## Windows installation
```bash
git clone git@github.com:Gerard-Janson/CodeGuard.git
cd CodeGuard
python -m venv venv

# Activate the environment:
# Command Prompt:
venv\Scripts\activate.bat
# PowerShell:
venv\Scripts\Activate.ps1

pip install -e .
```

## Run
```bash
codeguard
```
